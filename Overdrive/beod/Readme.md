#  beod  overdrive

This is a clone of the BEOD overdrive pedal from Friedman
Amplification, which is based, I think, on the Friedman BE-100.  The
schematic that was used for this seems similar to the pcbguitarmania
one, but I think I downloaded it from freestompboxes.

This was thought to be broken and I was debugging for several weeks
until I realized the kit I was using to test the bare PCB had a broken
wire.

This thing is $##@$@# loud.   This is a definite will-box pedal.

This pedal is verified.
